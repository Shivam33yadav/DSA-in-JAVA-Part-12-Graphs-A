# DSA in Java – Part 12: Graphs (A)

This repository contains my Java implementations and problem-solving practice focused on **Graph Data Structures**, covering fundamental graph concepts and algorithms.

## 📚 Topics Covered

- Introduction to Graph Data Structure
- Graph Terminology and Representation
- Adjacency Matrix
- Adjacency List
- Graph Creation Using Java
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Connected Components
- Path Finding in Graphs
- Cycle Detection in Undirected Graphs
- Cycle Detection in Directed Graphs
- Practice Problems Based on Graphs

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** VS Code
- **Concepts:** Graphs, BFS, DFS, Adjacency Matrix, Adjacency List, Recursion, Queues

## 🎯 Learning Objectives

- Understand graph structures and representations.
- Implement graphs using Java.
- Learn BFS and DFS traversal techniques.
- Understand graph connectivity and cycle detection.
- Improve problem-solving and algorithmic thinking.
